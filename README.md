# PSP Treasury & Settlement Intelligence

A Python-based fintech project focused on payment settlement liquidity simulation, PSP funding requirements, and treasury risk analysis.

## Technology
- Python
- NumPy
- Pandas
- Matplotlib
- Plotly
- Google Colab

## Project Objective
Simulate merchant early-settlement demand, estimate PSP liquidity requirements, and evaluate capital adequacy under different settlement scenarios.

## Status
Development in progress.
